# NexAIz Model Context Protocol Directory

A reference catalog indexing Model Context Protocol integrations, server definitions, and compute requirements.

## Overview

This project provides structured links and metadata for integrations indexed by [NexAIz](https://nexaiz.com).

### Key Integration Areas

- **System and Storage**: Connectors for local and cloud data sources.
- **Developer Workflows**: Tooling for code search, issue management, and continuous integration.
- **Data Stores**: Interfaces for structured and document databases.
- **Search and Retrieval**: Real-time information access services.

### Local Compute Guidelines

Hardware planning estimates for running local model backends alongside tool services:

- Compact models (3B to 8B): 4 to 8 GB unified or discrete memory.
- Mid-range models (14B to 32B): 12 to 24 GB video memory.
- Large models (70B+): 48 GB+ multi-accelerator configurations.

Interactive sizing tools and configuration generators are available on [nexaiz.com](https://nexaiz.com).
